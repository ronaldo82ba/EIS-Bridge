# 03 — EIS Bridge image brief (idea)

## Goal
Generate a marketing image set that **looks as polished as webshoppeph.com** but depicts **EIS Bridge-like activity**, for use on https://eisbridge.com/ (and optional WebShoppe EIS cards).

## Creative direction
- Match WebShoppe photo DNA: bright office, Filipino professionals, navy/blue UI accents, left text-safe area on heroes  
- Subject matter shifts to: Vendor API integration, async queue, POS still selling, multi-branch governance, CERT/PTT workshop (no seals)  
- Keep enterprise calm — trust, not hype  

## Shot list (priority)

| ID | Asset | WebShoppe analogue | EIS Bridge activity |
|----|-------|--------------------|---------------------|
| EB-01 | Hero 16:9 | hero-team.png | Team reviewing POS→Bridge→EIS queue on wall screen |
| EB-02 | Offer / feature | offer-eis.png | Close-up: POS sale + “queued” bridge status |
| EB-03 | Vendor | enablement energy | POS vendor laptop + API mapping workshop |
| EB-04 | Merchant | retail calm | Store counter operating while sync runs quietly |
| EB-05 | Enterprise | multi-location | Branches map into one bridge hub dashboard |
| EB-06 | Developers | systems.png | Engineers with docs / sandbox endpoints |
| EB-07 | CTA banner | hero crop | Wide soft office + blue bridge motif overlay |
| EB-08 | OG 16:9 | social | Same hero language, high contrast |

## Do / Don’t
**Do:** connector story, async queue, any-POS, white-label vendor shell  
**Don’t:** BIR logo, accreditation badges, “guaranteed compliance”, fake OR/SI legal seals  

## Dual track (optional)
- **Track A — Photoreal** (this brief; match WebShoppe)  
- **Track B — Isometric** (existing Canva/Gemini packs in CodeRnD)  

Use Track A for hero/trust; Track B for feature icons if needed.
